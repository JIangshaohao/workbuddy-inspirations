# 城市行程规划单文件 HTML

> 一页 HTML，把一座城市的三天走完 —— 时间轴 + 地图打点连线 + 四色分类。

## 这是什么

一个用于生成「城市多日行程规划页」的单文件 HTML 模板与样例。输入是一座城市、天数和主题偏好（历史文化 / 美食 / 自然 / 夜生活），产出是一页可直接打开、可交互的行程看板：

- **顶部 Banner**：居中放大标题 + 右侧徽章（天数 / POI 数 / 人均预算），Stripe 风格柔光渐变底。
- **顶部 Tab**：DAY1 / DAY2 / DAY3 分段控件，切换即刷新左侧列表与右侧地图。
- **左侧时间轴**：按时间顺序排列的 POI 卡片，POI 分**景点 / 美食 / 文化 / 购物**四类，用四套配色贯穿「卡片色条 → 分类标签 → 时间轴圆点 → 地图 Pin」。
- **右侧地图**：腾讯地图按顺序打点连线，Pin 带序号与分类配色；点击左侧卡片，地图平滑飞行到该点并弹出信息窗。

目标用户：需要出行前快速看清「每天去哪、怎么走、花多少」的人；以及想批量产出不同城市行程页的人（复用本模板，只换数据）。

本文件夹内的 `index.html` 是一个完整样例：**成都 3 日行程**（18 个 POI，覆盖历史文化、美食、自然、夜生活）。

## 使用方式

### 直接查看

在 WorkBuddy 预览面板中打开 `index.html`。地图底图 Key 由 WorkBuddy 本地代理注入，页面源码中不含任何明文 Key。

> 直接双击本地文件也能打开页面，但地图与路线不会显示（本地没有代理转发请求），此时页面会给出提示层。

### 换成别的城市

只改 `index.html` 中的 `ITINERARY` 常量即可，渲染逻辑无需改动：

```js
const ITINERARY = [
  {
    day: 1, date: '10/09', label: 'DAY 1', title: '老城人文 · 市井烟火',
    pois: [
      { id:'d1p1', time:'09:00', typeKey:'scenic', name:'人民公园 · 鹤鸣茶社',
        desc:'一句话卖点', lat:30.656930, lng:104.058613,
        duration:'1.5h', ticket:'免费', addr:'青羊区少城路12号',
        tag:'城市公园', intro:'详情文案（信息窗用）' }
    ]
  }
];
```

`typeKey` 取值：`scenic` 景点 / `food` 美食 / `culture` 文化 / `shop` 购物。

### 批量生成

配套技能 `.workbuddy/skills/city-itinerary-planner/` 沉淀了完整流程：调用腾讯地图能力解析真实坐标 → 组装数据 → 套用本模板 → 渲染校验。见该技能的 `SKILL.md`。

## 技术要点

1. **分类色单一来源**：`TYPE_META` 定义四类的渐变起止色与浅底色，卡片 chip、时间轴圆点、左侧色条、地图 Pin 全部由它派生，保证「同一类永远是同一个颜色」。
2. **Pin 用内联 SVG 生成**：`pinSvg(num, c1, c2)` 按序号与分类色即时生成 data URL，不依赖任何外部图片。
3. **路线先兜底再升级**：切天后先画直线（必定可见），再异步请求驾车路线替换；用自增 token 丢弃过期响应，避免快速切天时串线。
4. **地图飞行定位**：点击卡片调用 `map.easeTo({center, zoom:15, duration:760})` 平滑飞行，同时同步高亮时间轴与弹出信息窗；点击地图 Pin 反向联动左侧卡片并滚动到可见区域。
5. **Key 零明文**：走 `window._TMapSecurityConfig` 代理模式，HTML 中只有 `__WB_HTTP_PORT__` / `__WB_TMAP_SECRET__` 占位符，由运行时替换。
6. **信息窗换行修复**：腾讯地图默认给自定义信息窗内容加 `nowrap`，需显式重置，否则中文被截断。
