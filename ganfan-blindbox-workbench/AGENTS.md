# AGENTS.md — 吃了吗您 · 干饭盲盒工作台

## 项目简介

一个"专治今天吃啥"的吃饭盲盒工作台：点餐次卡片随机抽菜，抽到就记账，抽不起就问你要不要透支。

## 技术栈

- 语言/框架：单文件 HTML + 内联 CSS + 原生 JS（页面内不使用 jQuery）
- 运行环境：浏览器；宿主为 WorkBuddy「资料库」在线 page
- 依赖：**零外部依赖**。无 CDN、无字体、无图表库；图标为手绘风内联 SVG
- 数据层：资料库数据表（`__SMART_PAGE__.database` 运行时 SDK）

## 运行 / 构建方式

无构建步骤。

- 本地预览：双击 `output.html`（离线时自动降级为 localStorage，不报错）
- 线上使用：打开资料库页面 https://www.workbuddy.cn/space/d/fuLFSrmasJFqEEiSjogVYZ
- 重新发布：通过资料库技能 `page/import_html.py` 覆盖导入，或 `page/edit-flow.md` 流程

## 编码约定

- 本灵感源自「一键做同款」复制链路，属于**复制产物**：除非明确要改功能，否则不做重构、不改命名、不调样式。
- 若需修改，遵循「精准修改」原则，只动目标函数。
- **函数调用链必须单向（DAG）**：渲染函数之间严禁互调，统一由顶层 `refreshAll()` 调度。
- 新增字段时，必须同步「资料库数据表结构」与页面 `__SMART_PAGE__.database` 的读写字段名，两者不一致会静默丢数据。

## 注意事项

- **数据表 ID 是硬编码在 HTML 里的**：`output.html` 中的两个 ID 属于本账号（见 `MEMORY.md`）。换账号或换空间使用前，必须重新走 remap，否则页面读不到表、表现为"空白但无报错"。
- **`吃饭记录` 表初始为空表**，这是刻意为之（源数据属他人个人记录，未跨账号复制）。首次打开记录页为空属正常，抽一次卡即可产生数据。
- **饭票余额为负是合法状态**：透支确认后允许余额 `< 0`，不要在前端加"余额不足即拦截"的逻辑。
- 页面是草稿态（未发布）。要对外分享需单独走发布流程。
