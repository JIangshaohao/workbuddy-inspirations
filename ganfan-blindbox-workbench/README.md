# 吃了吗您 · 干饭盲盒工作台

> 点一下，替你决定今天吃啥；吃不起就问你一句——透支额度也要吃吗？

## 这是什么

一个专治"选择困难"的吃饭盲盒工作台。

**解决的问题**：每天到饭点就发呆，"今天吃啥"能纠结二十分钟；想控制开销又懒得记账；
想回顾"这周都吃了什么"却全靠回忆。

**做法**：把"选餐"变成抽卡，把"记账"挂在抽卡动作后面——抽到就记录、就扣钱，不用额外动手。

**目标用户**：一个人吃饭、想省点脑子也想省点钱的人。

## 效果

**主页**
- 顶部饭票余额与额度展示，可直接充值或重设额度
- 早餐 / 中餐 / 晚餐 / 宵夜四张卡片；未抽时显示"未抽"标签
- 点卡片 → 从该餐次的菜品里随机抽一道，展示大卡、价格、稀有度与一句话简介
- 心仪 → 点「吃吃吃」写入记录并扣减饭票；不满意 → 点重抽
- 抽到价格超出剩余饭票的菜 → 弹窗询问「透支额度也要吃吗」，确认后记录透支并允许余额为负

**菜品池页**
- 展示全部菜品与抽中概率说明（稀有度分级：普通 / 稀有 / 限定）
- 「嘴又馋了？加道菜」引导条：添加自定义菜品并**自选稀有度**，自定义菜同样进入抽取池

**记录页**
- 按日查看当天吃了什么与当日合计大卡
- 连续打卡天数与累计抽卡次数统计
- 花销一目了然
- 可生成**可保存的 PNG 分享卡片**

## 使用方式

1. 浏览器打开 https://www.workbuddy.cn/space/d/fuLFSrmasJFqEEiSjogVYZ
2. 主页点任一餐次卡片抽菜
3. 抽到想吃的点「吃吃吃」，不满意点重抽
4. 想加菜去「菜品池」页，用完点「记录」页看账单
5. 手机上使用：浏览器菜单 → 添加到主屏幕，可当 APP 用

## 数据模型

| 表 | 字段 |
| --- | --- |
| 菜品池 | 菜名、适合餐次（早餐/中餐/晚餐/宵夜）、口味（甜/咸/辣/酸/苦/鲜/香/淡/臭）、大卡、预估价格（元）、稀有度（普通/稀有/限定）、一句话简介、来源（默认池/自己加） |
| 吃饭记录 | 日期、餐次、菜名、口味、大卡、价格、稀有度、状态（已吃/丢弃）、是否透支 |

内置 29 道演示菜品（家常菜 + 外卖常见菜 + 宵夜饮品），含稀有度分级与手绘风 SVG 图标。

## 技术要点

- **单文件零依赖**：CSS / JS / 图标全部内联，图表与图标均为手写 SVG，离线可用。
- **数据在线存储**：页面通过资料库运行时 SDK（`__SMART_PAGE__.database`）直接读写自己的两张数据表，多设备打开同一页面即见同一份数据。
- **页面 ↔ 数据表绑定**：两张表挂在页面节点下，关系记录在页面的数据库绑定里；导入时一次性写入。
- **离线降级**：SDK 不可用时自动退回 localStorage，联网后同步。
