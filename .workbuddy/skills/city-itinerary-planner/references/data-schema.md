# 数据契约 — ITINERARY / TRIP

模板中所有行程内容都由两个常量驱动：`TRIP`（页面级信息）与 `ITINERARY`（行程数据）。换城市只改这两个常量。

## TRIP

```js
const TRIP = {
  city: '成都',                    // 城市名（用于文案，不参与渲染逻辑）
  tag: 'CHENGDU · 成 都',          // Banner 顶部小标签（英文 · 中文，中文建议字间加空格）
  title: '烟火<em class="accent">蓉城</em>，慢煮三日',  // Banner 主标题，可用 .accent 强调
  subtitle: '一句话副标题，60-90 字，用顿号串起当天最亮的几个点',  // Banner 副标题
  center: [30.66, 104.06]          // 地图初始中心点 [lat, lng]（GCJ-02）
};
```

同时需改：

- `<title>` 标签
- `BUDGET` 常量（人均预算，数字，渲染时自动加千分位与 `¥`）

## ITINERARY

```js
const ITINERARY = [
  {
    day: 1,                       // Number，天序号，从 1 开始
    date: '10/09',                // String，展示用日期
    label: 'DAY 1',               // String，Tab 上行标签
    title: '老城人文 · 市井烟火',   // String，当日主题（Tab 下行 + 侧栏标题）
    pois: [ /* PoiObject... 按时间升序 */ ]
  }
  // ... 更多天
];
```

## PoiObject

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | String | ✓ | 全局唯一，建议 `d<天>p<序号>`。用于地图 marker id 与卡片定位 |
| `time` | String | ✓ | 建议到访时间，`HH:MM` 24 小时制。时间轴按此顺序渲染 |
| `typeKey` | String | ✓ | 分类键，只能是 `scenic` / `food` / `culture` / `shop` |
| `name` | String | ✓ | 地点名。含子项时用 ` · ` 连接（如 `人民公园 · 鹤鸣茶社`） |
| `desc` | String | ✓ | 一句话卖点，30-45 字，卡片展示，最多两行 |
| `lat` | Number | ✓ | 纬度（**GCJ-02**） |
| `lng` | Number | ✓ | 经度（**GCJ-02**） |
| `duration` | String | ✓ | 建议停留时长，如 `1.5h`、`4h` |
| `ticket` | String | ✓ | 门票 / 人均消费，如 `¥80`、`免费`、`人均 ¥60-80` |
| `addr` | String | ✓ | 区 + 街道级地址，卡片元信息行展示 |
| `tag` | String | ○ | 地点标签（如 `世界文化遗产 · 5A级景区`）。当前模板未渲染，保留供扩展 |
| `intro` | String | ✓ | 详情文案，60-120 字，仅用于地图信息窗 |

> `desc` 与 `intro` 是**两份不同粒度的文案**：`desc` 是卡片上的一句话钩子，`intro` 是信息窗里的完整介绍。不要复用同一段文字。

## 分类约定（typeKey → 视觉）

| typeKey | 中文 | 主色 | 使用场景 |
| --- | --- | --- | --- |
| `scenic` | 景点 | 绿 `#059669` | 公园、山岳、自然景观、观景地 |
| `food` | 美食 | 橙 `#EA580C` | 餐厅、小吃街、夜市、酒吧街 |
| `culture` | 文化 | 紫 `#4F46E5` | 博物馆、古迹、寺庙、非遗演出 |
| `shop` | 购物 | 粉 `#DB2777` | 商业街、商圈、文创街区 |

配色由 `TYPE_META` 统一提供，新增地点时**不要**新增分类，四类是产品的固定语义。

## 编排约束

1. **每天 5-7 个 POI**，以 6 个为宜。少于 4 个显得空，多于 8 个时间轴需滚动过多。
2. **同一天必须顺路**：相邻 POI 的地理距离尽量短；跨城区（如市区 + 远郊）安排在同一天时，应形成单向的「出发 → 远郊 → 返城收尾」动线。
3. **时间递进合理**：首站不早于 07:30，末站不晚于 22:00；相邻站点间隔要能覆盖前一站的 `duration` 与通勤时间。
4. **每天至少覆盖 3 个分类**，整体四类都要出现。
5. **三天主题要有差异**，建议模板：
   - DAY 1 老城核心 —— 历史文化 + 市井美食
   - DAY 2 城市名片 —— 自然/动物 + 人文 + 夜生活
   - DAY 3 远郊/深度 —— 自然 + 遗产 + 收尾演出

## 完整示例

```js
const ITINERARY = [
  {
    day: 1, date: '10/09', label: 'DAY 1', title: '老城人文 · 市井烟火',
    pois: [
      {
        id: 'd1p1', time: '09:00', typeKey: 'scenic',
        name: '人民公园 · 鹤鸣茶社',
        desc: '百年老茶馆里泡一碗盖碗茶，成都的慢生活从清晨开始。',
        lat: 30.656930, lng: 104.058613,
        duration: '1.5h', ticket: '免费 · 茶水¥20起', addr: '青羊区少城路12号',
        tag: '城市公园 · 百年茶馆',
        intro: '人民公园始建于1911年，是成都最老的公园。园内鹤鸣茶社建于1923年，竹椅、盖碗、长嘴铜壶，是"休闲之都"的活标本。'
      }
      // ...
    ]
  }
];
```

## 预算口径

`BUDGET` 为**人均 N 天合计**，建议按下面四项加总后向上取整：

| 项 | 估算方式 |
| --- | --- |
| 门票 | 各 POI 门票之和（免费的按 0） |
| 餐饮 | 天数 × 约 150 元 |
| 交通 | 市区地铁/打车按天 40-60 元；含远郊往返再加 100-150 元 |
| 住宿 | (天数 - 1) 晚 × 经济型均价 200-250 元 |

## 坐标校验清单

- [ ] 每个 `lat` 都落在城市合理范围内（成都约 lat 30.5-31.1 / lng 103.5-104.5）
- [ ] 用 `geocoder` 解析时返回的 `level` 不低于 10；低于 10 说明落到了行政区中心点，必须换 `poi_search` 重查
- [ ] 返回的 `district` 属于目标城市
- [ ] 坐标系统一为 GCJ-02，不与 WGS-84 混用
