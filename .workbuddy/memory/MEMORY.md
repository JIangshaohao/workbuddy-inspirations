## 项目约定（长期有效）

### 一灵感 = 一文件夹（用户明确要求，2026-10-08）

- 仓库整体会上传到 GitHub，且会持续用多个灵感生成多种不同内容。
- **每创建一个新灵感，必须单独新建一个文件夹，一个灵感项目对应一个文件夹。**
- 该文件夹内**必须**包含三个文件：
  - `AGENTS.md`
  - `README.md`
  - `MEMORY.md`（用户原话写为 `Memory.md`，落地统一用大写 `MEMORY.md`）
- 详细规则与三件套模板见仓库根 `AGENTS.md`；仓库级上下文见根 `MEMORY.md`。

### 执行流程（新灵感时必做）

1. 在根目录建 kebab-case 英文文件夹
2. 创建 `AGENTS.md` / `README.md` / `MEMORY.md`
3. 回到根 `MEMORY.md` 的「灵感索引」表追加一行
4. 再开始写代码
