**产出**：
- 主产物 `old-photo-restoration/index.html` —— 单文件、零依赖、零外链的浏览器端四步修复工作台（去噪 / 亮度对比度 / 色彩增强 / 锐化），支持拖拽与 Ctrl+V 粘贴、前后对比滑块、逐阶段量化指标表、PNG 另存为（File System Access API）、修复说明 .md 与参数报告 .json 导出。
- CLI 参考实现 `scripts/beautify.py`（与页面版影调映射一致，去噪用 OpenCV NLM）。
- 验收工具 `tools/make_test_photo.py` + `tools/verify_page.js`（CDP 驱动无头 Chrome，9 项指标口径）。
- 三件套 + `.gitignore`；根 `MEMORY.md` 灵感索引已追加一行。

**关键修复（均已沉淀到灵感 MEMORY.md）**：
1. **通道布局错位（严重）**：`stepDenoise` 写平面布局、管线按交错读取，导致色彩整体崩坏（暖偏 64.7 → 精确 0）。已修，并加为回归项。
2. **eps 未实测定标**：初版 `eps=787` 使自适应系数中位数仅 0.29，纹理被抹平。做参数扫描后定标。
3. **线性提亮压死高光**：裁剪率 34.75%。改 gamma 提亮 + smoothstep S 曲线，回到 +2.1pp。
4. **HSV 抬高 S 会拉低亮度**（Python 版）：155.2 → 150.3。改 luma 保持式混合。
5. **平坦区掩膜退化**：512 桶直方图使阈值算成 0，缩放后图片 `flat_noise` 全为 null。改 4096 桶 + 10–40 分位带。
6. **模板字符串未转义反引号**：截断模板，整个 script 块语法错误。用"抽取 script + `node --check`"秒级定位。

**方法论收获**：
- 图像算法的验收必须用**逐阶段指标 + 参数扫描**，不能靠肉眼判断缩略图。
- 整图 Laplacian 方差**不能**用于跨"处理前/后"比较（颗粒会抬高它），为此新增「纹理保留」指标（纹理区高频能量比），并直接对应"塑料感"这一用户关切。
- 单页 HTML 的端到端验收走 CDP，用 `DOM.setFileInputFiles` 走真实文件选择器路径而非绕过 UI。

**待办**：无。页面已验收通过（9/9）。
