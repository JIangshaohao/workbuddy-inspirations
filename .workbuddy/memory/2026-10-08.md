### 关键技术结论

- **腾讯地图 Key 零明文**：按 `geo-map-compliance-guard` 要求走 `window._TMapSecurityConfig` 代理模式，HTML 只保留 `__WB_HTTP_PORT__` / `__WB_TMAP_SECRET__` 占位符；页面需在 WorkBuddy 预览面板打开，本地直开显示兜底提示层。
- **POI 坐标必须真实解析**：用腾讯位置服务 WebService `geocoder` 批量解析；`geocoder` 对「九眼桥」「都江堰南桥」「都江堰西街」等词会落到行政区中心点（`level` ≤ 4），必须改用 `place/v1/search` 重查。
- **路线策略**：切天后先画直线兜底（保证「按顺序连线」必定可见），再用 `TMap.service.Driving` 异步替换为真实道路；用自增 `routeToken` 丢弃过期响应。
- **踩坑**：腾讯地图给自定义 InfoWindow 注入 `white-space:nowrap` → 中文被截断，需 `.iw, .iw *{ white-space:normal !important }`；地图比例尺与版权信息固定在左下角，图例必须放右下。
- **渲染校验方法**：本机 Chrome 无头模式截图（`--headless=new --enable-unsafe-swiftshader --virtual-time-budget`），QA 期间临时注入直连 Key，确认后删除 QA 副本。

### 落地动作

- 4 套配色预设（极光蓝 / 星云紫 / 翡翠绿 / 熔金橙），CSS 变量驱动，写入 `localStorage`。
- 根 `MEMORY.md` 追加灵感索引行；本灵感 `MEMORY.md` 记录架构决策与踩坑。

### 关键技术结论

- **SVG 表现属性不接受 `var()`**：`setAttribute("stroke","var(--x)")`、`<stop stop-color="var(--x)">` 全部静默失效。改为 `el.style.stroke = "var(--x)"` / `style="stop-color:var(--x)"`，渐变用 `createElementNS` 手工构建。
- **`.reveal.in{transform:none}` 压制 hover**：与 `.stat:hover` 等特异性相同（0,2,0），后写者胜出。解法是动画结束后摘掉渐入类，把 transform 交还组件。
- **CSS Grid span 必须算总格数**：初版 6 列下 `3+3+2+2+2+3`=15 格，非 3 行整数倍（18），自动布局留下参差空档。改为 `4+2+2+2+2+2`=18 格后三行填满。
- **移动端导航溢出**：6 个中文导航项 + 配色圆点 + 复制按钮在 390px 下溢出被裁。解法是把配色预设移到页脚，并在 ≤480px 把复制按钮降级为纯图标（实测 navScrollW == navClientW == 319）。
- **验证方法升级**：不再依赖截图推断，改用 Node 直连 Chrome DevTools Protocol（`--remote-debugging-port`，Node 22 自带 WebSocket），可同时拿到「渲染节点计数 + 控制台异常 + 分区裁剪截图 + 主题切换后的 computed style」。实测确认 `--primary` 与 SVG 渐变 stop-color 都随主题正确变更。
- 最终校验：`RESUME_DATA` 与 `data.json` 深度一致、内联 JS 语法通过、CSS 括号平衡 240 对、零外部资源引用、零控制台错误、移动端零横向溢出。
