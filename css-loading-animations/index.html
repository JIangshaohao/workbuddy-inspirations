CSS 加载动画合集

8 种常用 Loading 效果，全部由 @keyframes 与 transform 驱动，运行在合成层上。每个动画都带有 prefers-reduced-motion 降级方案。点击卡片底部的按钮即可复制对应的 CSS。

脉冲圆点

弹跳柱条

五根柱条交错伸缩，音频可视化风格，适合媒体类加载。

波纹圆圈

渐变锥形旋转器

打字指示器

骨架屏微光
