# 老照片修复工作台

> 一个不联网、不上传、双击即用的老照片修复页面。

## 这是什么

把泛黄、颗粒感重、轻微模糊的老照片，按固定工序修复到"自然清晰"的状态。

打开 `index.html`，选一张照片，拖动参数，导出 PNG——**全过程在你的浏览器里完成，没有任何网络请求，照片不会离开本机**。

面向的场景是：你手上有一张真实的扫描件或翻拍件，需要一个**不依赖云端、不上传隐私、结果可复现**的修复方案。它做的是**保守修复**：只做去噪、提亮、增强、锐化四件事，不生成、不重绘、不编造原片不存在的细节。

## 使用方式

1. 双击 `index.html`（Chrome / Edge 均可，`file://` 下直接可用）
2. 点击选择照片，或把照片**拖进页面**，或直接 **Ctrl+V 粘贴**
3. 调整参数（默认值已针对典型老照片标定，通常可直接用）
4. 点「开始修复」→ 看对比效果 → 点「另存为 PNG」选保存位置

> 「另存为」会弹出系统保存对话框，可自选目录与文件名（Chrome / Edge）。
> 若浏览器不支持，会自动回退为下载到默认下载目录。

## 四道工序

| 步骤 | 作用 | 算法 | 默认参数 |
|---|---|---|---|
| ① 去噪 | 去除胶片颗粒、细霉点 | YCbCr 分离的自导向滤波 | 亮度 eps=120 / 色度 eps=360，半径 3 |
| ② 亮度/对比度 | 提亮暗部、增强层次 | gamma 提亮 + smoothstep S 曲线 | γ=1/1.15，k=0.40 |
| ③ 色彩增强 | 修正泛黄偏色 | luma 保持式饱和度混合 | ×1.4 |
| ④ 锐化 | 增强边缘细节 | 反锐化掩膜 + 肤色降权 | +0.30，σ=1.2 |

几个关键设计选择，都对应一个具体的质量问题：

- **去噪在 YCbCr 空间分离处理**：亮度通道温和去噪（保皮肤纹理与五官轮廓），色度通道用 3 倍强度去噪（除色斑与彩色噪点）。实测比 RGB 逐通道方案同时做到了「降噪更强 + 纹理更完整 + 色彩更保真」。
- **亮度用 gamma 而不是线性偏移**：线性 `src + beta` 会把通道值 >196 的像素全部并到 255，实测高光裁剪率 35%——亮部细节整片丢失，与"增强层次感"直接冲突。
- **对比度用 S 曲线而不是线性增益**：smoothstep 值域严格 [0,1]，中段增强而两端渐近，不产生任何额外裁剪。
- **饱和度用 luma 保持式混合**：在 HSV 里抬高 S 会压低暖色像素的蓝通道，实测把平均亮度拉低约 9 个灰阶，与"提亮"互相打架。
- **面部保护**：YCrCb 肤色掩膜（羽化后）内锐化量降至 35%，避免面部出现过度锐化的白边伪影。

## 量化验证

页面会实时输出**逐阶段指标**，不是"看起来还行"：

| 指标 | 口径 | 典型读数（仿真老照片） |
|---|---|---|
| 平区噪声 σ | 只统计"平坦但非退化"区域（局部方差 10–40 分位带） | 5.24 → 2.05（−61%） |
| 纹理保留 | 纹理区高频能量相对原图的比值 | 去噪后 92%，锐化后 136% |
| 平均亮度 | 加权亮度均值 | 152.4 → 158.2 |
| 平均饱和度 | `(max−min)/max` 均值 | 107.7 → 130.1 |
| 高光裁剪率 | 通道值落到 0/255 的占比 | 15.0% → 17.1% |

**怎么读这些数字**：

- 判断去噪是否过度，看**「纹理保留」低于 70%** 就是塑料感信号，把去噪强度调低一档。
- 不要用整图 Laplacian 方差比较"修复前 vs 修复后"——胶片颗粒会大幅抬高它，颗粒多的一方永远赢。它只能在相邻阶段间比较。
- 平区噪声的口径特意排除了纯白/纯黑过曝退化区（那里方差恒为 0、本来就没有噪声，混进来会把结果稀释成无意义的 0）。

## 性能

| 输入规模 | 耗时（本机实测） |
|---|---|
| 0.5 MP | < 1 秒 |
| 2.5 MP（限边长 1500 后） | 约 3 秒 |
| 9 MP（3000×3000，原始分辨率） | 约 11 秒 |

处理期间页面会短暂无响应，这是纯前端计算的正常表现。不需要全分辨率细节时，把左侧「最大处理边长」调到 2000~3000 px 可显著提速。

## 技术要点

1. **导向滤波而非非局部均值**：NLM 复杂度 O(N·窗口面积)，在 JS 里处理高分辨率图不可接受；导向滤波同为边缘保持滤波且为 O(N)。系数 `a = 局部方差 /（局部方差 + eps)`——平坦区 a→0 被强平滑，高方差区 a→1 近似保留原样。
2. **盒式滤波用可分离滑动窗口**：O(N) 而非 O(N·r²)，这是整个页面的性能基础。
3. **路径安全（`file://` 环境）**：页面不读取任何本地文件路径下的外部资源，全部自包含。
4. **导出用 File System Access API**：`showSaveFilePicker` 让用户自选保存位置，不支持时自动回退。

## 局限

- **不做生成式修复**：大面积霉斑、划痕、撕裂、缺失区域属于结构性损伤，本工具只能略微弱化，无法填补。它保留了图像中所有高对比结构——这是"不编造"的代价。
- **不做超分辨率放大、不做黑白上色**。
- 严重失焦或分辨率过低的原片，只能做有限改善。

## 附：Python CLI 参考实现

`scripts/beautify.py` 提供同样的四步管线，用于批量处理。它与页面版**影调映射一致**（gamma 提亮 + S 曲线 + luma 保持式饱和度），但去噪使用 OpenCV 的非局部均值（`fastNlMeansDenoisingColored`），对重度颗粒的画质略优。

```bash
PY="C:/Users/Soul/.workbuddy/binaries/python/envs/default/Scripts/python.exe"
"$PY" scripts/beautify.py input/old.jpg -o output/restored.png \
  --denoise medium --brightness 1.15 --contrast 1.2 --saturation 1.4 --sharpness 1.3 \
  --compare output/compare.png --report output/report.json
```
