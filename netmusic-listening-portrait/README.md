# 你的听歌画像 · 网易云音乐

> 把 8 年 10 个月的听歌数据，摊成一份可以慢慢翻的杂志。

## 这是什么

一份**单文件 HTML 数据可视化报告**，用真实听歌数据回答一个问题：*我到底是怎么听歌的？*

数据来自网易云音乐账号本身——不是模拟数据、不是估算值。整份报告静态预渲染，
双击 `index.html` 即可打开，也能直接发到手机上扫码阅读，**不需要联网、不需要任何依赖**。

## 报告结构

| 章节 | 内容 |
| --- | --- |
| Hero | 一句话画像 + 账号年龄 + 数据口径 |
| 01 核心数字 | 收藏数、累计播放、总时长、歌手/专辑数、歌单数 |
| 02 常听歌曲与歌手 | 全部时间 Top 10 歌曲、长期核心歌手 |
| 03 曲风偏好 | 自建歌单 vs 订阅歌单、时代光谱、热度光谱 |
| 04 收藏 × 实际播放 | 收藏广度与回放深度的反差、「囤而不听」名单、集中度 |
| 05 陪伴最久 × 最近靠近 | 全部时间榜与最近一周榜的重叠分析、曲风年代转向 |
| 06 音乐坐标 | 收藏云 + 已播高亮（发行年代 × 热度） |
| 07 我的听歌方式 | 两种听歌人格 + 画像标签 |
| 08 阶段总结 | 一句话收束 + 数据口径说明 |

## 效果

- 深色沉浸背景，Hero 为唱片机特写大图 + 深色渐变蒙版
- 大标题 + 大数字 + 轻量内联 SVG 图表，错落分栏
- 移动端完整适配，无横向溢出

## 使用方式

1. 双击 `index.html`，或拖进浏览器
2. 想用手机看：把文件发到手机，用浏览器打开即可（图片已内联，离线可读）
3. 重新生成自己的版本：见 [`AGENTS.md`](./AGENTS.md) 的构建流程

## 技术要点

- **构建期预渲染**：所有数值在 Node 构建脚本里写死进 HTML，页面运行时零数据依赖
- **零外链**：Hero 图（约 73KB）、头像、图表（内联 SVG）全部内嵌，单文件自洽
- **渐变揭示**：内容默认可见，仅在支持 JS 时叠加滚动淡入，JS 失效不影响阅读
- **口径诚实**：拿不到的数据直接隐藏，不编造；每章数字都能从数据源复算
