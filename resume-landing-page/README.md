# 网页简历 · Landing Page

> 把一份简历变成一张会讲故事的单页站点 —— 单文件、零外链、双击即开。

## 这是什么

绝大多数简历的问题不是"内容不够"，而是**信息密度错了**：所有内容平铺在同一层级，招聘方要在 30 秒内自己找出重点。

这个灵感把简历重组为 Landing Page 的**金字塔叙事骨架**：

| 区块 | 回答的问题 | 阅读时长 |
| --- | --- | --- |
| HeroCard | 你是谁、做什么方向、是否在找机会 | 5 秒 |
| 核心数据看板 | 你的量级有多大 | 10 秒 |
| 时间倒序经历 | 你在什么样的环境里解决了什么问题 | 60 秒 |
| 技能雷达 | 能力结构是 T 型还是扁平的 | 20 秒 |
| 项目精选 | 你最拿得出手的三到六个结果 | 60 秒 |
| 推荐评价 | 别人怎么评价和你共事 | 15 秒 |

**目标用户**：需要一份"能在链接里投出去"的简历的技术从业者，尤其是后端／全栈工程师。

## 效果

深色极光渐变底 + 玻璃拟态卡片，四个可切换的配色预设（极光蓝 / 星云紫 / 翡翠绿 / 熔金橙），滚动时有渐入动画、数字滚动、雷达图绘制、技能条生长、卡片光标聚光。

## 使用方式

1. 打开 `data.json`，把里面的内容替换成你的真实履历。
2. 打开 `output.html`，找到 `<script>` 里的 `const RESUME_DATA = { ... }`，把同一份 JSON 原样粘进去。
3. 双击 `output.html` 即可预览；`Ctrl+P` 可直接导出 PDF（自带浅色打印样式）。

> 也可以只改 `output.html` 里的 `RESUME_DATA`（渲染只认它）。但为了 `data.json` 不变成死数据，建议两处同步。

## 硬约束（已全部满足）

- 单个 HTML 文件，CSS / JavaScript 全部内联
- 零外链：无 CDN、无外部字体、无图床占位图；项目封面由纯 CSS 渐变生成
- 系统字体栈，不加载任何字体文件
- 响应式：1280 / 1024 / 768 / 640 四档断点
- 尊重 `prefers-reduced-motion`：系统开启"减少动态效果"时，动画与滚动监听全部关闭
- 深色 + 渐变极光主题，主色通过 CSS 变量一行可换
- 无 emoji，图标全部为内联 SVG

## 技术要点

- **数据驱动渲染**：所有区块由 `RESUME_DATA` 经 JS 渲染，改数据不用碰结构。
- **雷达图**：`document.createElementNS` 手绘六轴 SVG，包含网格环、轴线、数据多边形与顶点，进入视口时以 `scale` 变换展开。
- **计数动画**：从展示值里提取首个数字，保留前后缀（`99.9%`、`20+`、`1200h` 都能正确滚动）。
- **时间轴进度线**：`transform: scaleY()` 跟随滚动进度，只用 GPU 属性。
- **主题切换**：`--primary` 与 `--primary-rgb` 双写，CSS 变量驱动全局；选择写入 `localStorage`。
- **打印样式**：`@media print` 中重定义颜色变量为浅色方案，导出 PDF 不会白底白字。

## 文件

```
.
├── AGENTS.md      # 项目规则：技术栈、目录约定、编码标准
├── README.md      # 本文件
├── MEMORY.md      # 长期上下文：架构决策、踩坑、外部资源
├── data.json      # 结构化简历数据（可替换复用）
└── output.html    # 最终产物
```
