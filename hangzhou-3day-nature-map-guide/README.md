# 杭州三日自然山水游 · 地图行程指南

> 一份打开即用的单文件地图行程页：左边看行程，右边看地图，点击即联动。

## 这是什么

面向「杭州 3 天自然山水游」的自助行程地图。把三天的 12 个站点、每段路的交通方式与耗时、
以及每个点的看点与到达贴士，压进一个 HTML 文件里，双击即可打开，不需要装任何东西。

解决的问题：攻略散落在图文里，看文字想象不出动线，看地图又对不上行程顺序。
本页把「行程」和「地图」放在同一屏内联动——点站点，地图飞过去弹卡片；点标记，左边列表同步高亮。

目标用户：想按天分线走杭州、又希望顺手把行程存进手机地图的人。

## 效果

- 全屏腾讯地图底图，三天各自一种配色：Day1 湖蓝、Day2 茶绿、Day3 苇棕。
- 地图上按天绘制**编号标记**（1–12 全局序号）与**每日真实足迹路线**（沿实际道路的折线）。
- 左侧面板：行程标题、日期区间、统计（3 个日程 · 12 站 · 55 km），按天分组的站点清单，
  站点之间标注下一程的交通方式、距离与耗时；面板底部为每日图例。
- 点击面板站点或地图标记，双向联动弹出信息卡片：名称、简介、亮点标签、到达贴士。
- 右下角二维码可跳转手机端；窄屏（≤820px）时面板收到底部、二维码隐藏。

## 使用方式

1. 双击 `index.html`，或拖进浏览器。
2. 点左侧任一站名 → 地图定位并弹出该站信息卡片。
3. 点地图上任一编号标记 → 左侧列表同步高亮该站。
4. 点某一天的分组标题 → 只显示该天，再点一次恢复全部。
5. 想让手机也能看：扫右下角二维码。

## 技术要点

- **鉴权**：使用腾讯地图官方 `_TMapSecurityConfig` 代理模式。前端不携带明文 Key，
  SDK 从官方 CDN 加载且 URL 不含 `key` 参数，密钥由本地代理服务换取。
  `serviceHost` 中的 `__WB_HTTP_PORT__` / `__WB_TMAP_SECRET__` 由运行环境注入，生成时原样保留。
- **数据**：行程以结构化 JSON 内嵌在 `<script type="application/json">` 中，
  含站点坐标、简介、标签、贴士，以及段间路线的 `mode / distance / duration / polyline`。
- **轨迹还原**：腾讯路线接口返回的 `polyline` 是压缩增量数组，
  首点为绝对经纬度（纬度在前），其后每两个值是 (Δlng, Δlat)，单位 1e-6 度，逐项累加还原为 `[lat,lng]`。
- **标记**：每天一个配色，编号直接烘焙进 SVG 图钉（`data:image/svg+xml`），
  以 `MarkerStyle.src` 传给 `MultiMarker`，避免文本定位在不同缩放下漂移。
- **信息卡片**：`TMap.InfoWindow` + `enableCustom: true`，内容为自建 DOM 字符串，
  这样标题、标签、贴士的排版完全可控。
- **视野留白**：`fitBounds` 的 `padding` 显式避开左侧面板与右下角二维码，
  否则贴边的站点会被面板压住，看起来像「少了一个点」。
